# Document font

`NotoSans-Regular.ttf` is the unmodified Noto Sans Regular font from the
Noto project, distributed with its [SIL Open Font License](OFL.txt).

Only PDF document typography uses this bundled font. The monument lettering
retains the existing system-serif presentation and is rasterized by the local
browser. No system font files are copied or redistributed. The font license
does not select a license for MonumentStudio; project publication remains an
owner decision. Document text is checked for supported glyphs before export;
the font is not a claim of support for every writing system.
